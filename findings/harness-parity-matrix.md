# Stage harness parity — v0.6.0

Audit date: 2026-10-20. Baseline: fetched `origin/main` at
`72156d7fe314c853fe38a2aaa408b75dc2388ab9`. This compares the **stage adapters**,
not interactive chat drivers. Code links are pinned to that baseline. Pending
PRs below do not change a baseline cell's rating.

**Supported** means the adapter implements the named capability under its documented
execution path. **Partial** means a material limitation, conditional path, or
known defect remains. **Gap** means the requested capability has no equivalent
implementation. These ratings are code findings, not a claim of live CLI or
cross-platform certification. No live Claude calls were made; usage findings
were verified with fixtures and vendor source inspection in the linked PRs.

## Prioritized disposition

1. **Copilot host safety:** existing [#7394](https://github.com/Agent-Clubhouse/Goobers/issues/7394), implemented independently in [PR #7585](https://github.com/Agent-Clubhouse/Goobers/pull/7585). Do not duplicate. Shared macOS signal isolation [#7395](https://github.com/Agent-Clubhouse/Goobers/issues/7395) and Codex/Linux verification [#7396](https://github.com/Agent-Clubhouse/Goobers/issues/7396) remain separately tracked and assigned.
2. **Copilot runtime isolation:** [#2816](https://github.com/Agent-Clubhouse/Goobers/issues/2816), implemented in [PR #7637](https://github.com/Agent-Clubhouse/Goobers/pull/7637). Isolate stages with resolved environment/keychain-backed model credentials without copying login files. Preserve ordinary stored CLI login through an explicit reduced-isolation compatibility path and preflight warning; enforced isolation must never fall back.
3. **Repair accounting:** independent fixture-tested fixes [Claude #7592](https://github.com/Agent-Clubhouse/Goobers/pull/7592), [Codex #7589](https://github.com/Agent-Clubhouse/Goobers/pull/7589), [Copilot #7605](https://github.com/Agent-Clubhouse/Goobers/pull/7605). Claude/Codex cumulative resume totals need deltas; independent Copilot repair sessions need summing once. Copilot's suspicion was undercount, not double-count.
4. **Claude unattended permissions:** [PR #7579](https://github.com/Agent-Clubhouse/Goobers/pull/7579) supplies explicit `dontAsk` when allowlist/custom argv omit a mode, preserving caller-selected modes and existing unrestricted bypass. The omitted mode can select CLI `auto` under version/auth feature gates; code inspection does not justify claiming every omitted-mode invocation uses auto.
5. **Remaining gaps filed and assigned to `masra91`:** [#7617 DSL-declared MCP required-ness](https://github.com/Agent-Clubhouse/Goobers/issues/7617), [#7618 Windows Copilot actual-session startup gate](https://github.com/Agent-Clubhouse/Goobers/issues/7618), [#7619 Claude external MCP allowlist](https://github.com/Agent-Clubhouse/Goobers/issues/7619), [#7620 Codex normalized events/cache usage](https://github.com/Agent-Clubhouse/Goobers/issues/7620), [#7621 preflight capability floors](https://github.com/Agent-Clubhouse/Goobers/issues/7621).

## Policy boundaries and verification limits

- The external MCP startup difference is **not** automatically a Copilot bug: `requiredmcp.go` explicitly allows optional declared servers. The DSL is the source of truth; #7617 proposes per-server `required` with one documented default across adapters. No blanket external-server failure gate was added.
- A tool availability list is not a complete process sandbox. Shell/interpreter escape forms and host signal isolation need substrate enforcement; deny rules are defense in depth.
- Windows adapter compilation/fixtures do not prove native CLI behavior or containment. No Windows machine or live model was used for this audit.
- Wrapper/custom-argument paths have negotiated or unobservable capabilities. They must not inherit claims established only for direct, adapter-controlled sessions.
- Stored-login compatibility ruling: Copilot is the primary local harness. A plain `copilot login` must continue working in v0.6.0. Without a scoped model credential, keep the ambient home and warn about reduced isolation; never copy a renewable login file into another home. Explicitly isolated stages do not use this fallback.
- Copilot compatibility verification: the #7637 preflight environment preserved an existing login with read-only SDK `auth.getStatus` on installed CLI 1.0.100. The check created no model session and copied no login file. This is authentication-state evidence, not a model-entitlement or Windows check.
- Pending PRs require independent review and CI. This report records baseline behavior and proposed fixes; it does not certify them merged.
