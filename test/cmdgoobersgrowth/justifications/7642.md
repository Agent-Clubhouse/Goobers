# Unify root and attribution identity (#7642)

The nine additional non-test lines in `cmd/goobers/telemetryidentity.go`
preserve correlation for roots that historically wrote different lifecycle and
journal-attribution IDs. The adapter now selects the canonical `.instance-id`
for new telemetry while retaining the old `goobers.instance.id` value only
when the root-scoped alias resolver proves that both IDs belong to this root.

This logic belongs in the command package because it wires the existing
OpenTelemetry resource keys and their backward-compatibility contract. Identity
validation, migration, alias persistence, and lookup remain reusable in
`internal/instance`; no shared growth snapshot is changed.
