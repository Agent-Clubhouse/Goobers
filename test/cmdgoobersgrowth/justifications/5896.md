# #5896: name the blast radius of a rejected config directory

Growth: +19 non-test lines and +0 files in `cmd/goobers`.

The config directory is admitted as one unit (CFG-023, fail closed), so one
invalid workflow keeps its healthy siblings from loading. The commands that
report that rejection (`validate`, `status`, `workflow show`, `features`
and `up`) now say so and list the files with errors and the files that are
not loaded only because of them. Each command gains one call (`up` also
gains the `ErrInvalidConfig` guard around it) at the point where it already
prints the rejection. `validate`'s invalid-directory tail moves into a small
`reportInvalidConfigDirectory` helper so `runValidateConfig` stays within its
baselined body length.

## Could any of it live elsewhere?

It already does. The scope computation and its rendering live in
`internal/instance` (`configscope.go`), next to `LoadConfigDir`. What is
left in `cmd/goobers` is the per-command call at each existing error site.
