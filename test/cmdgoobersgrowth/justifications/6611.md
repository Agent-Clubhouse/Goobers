# #6611: Resolve and quarantine goober instruction failures

The command package gains runtime loader and quarantine helpers because
instruction resolution and daemon startup admission happen at command-owned
scheduler, validation, preflight, status, and snapshot boundaries. The shared
`instance.ConfigSet` already carries definition provenance, so keeping the fix
in `cmd/goobers` wires that provenance into the existing command runtime
without changing API or config types.

The added daemon code also converts late instruction read failures into
per-workflow startup refusals and instance-log diagnostics. That must remain in
the scheduler construction path so one bad gaggle can be quarantined without
preventing healthy gaggle runtimes from being built and served.
