# Contained attempt recovery and observation validation

The command layer selects exact parent or generated-child custody from the
existing authenticated daemon principal. Shared adapters validate journal
observations, completion carriers, reviewer evidence and bounded artifact reads
before handing them to the existing journal/surrender stores. This is daemon
assembly over host-owned identity, policy, queue and journal state; reusable
contract and storage behavior remains in childpod and triggerqueue.

The paired parent production route and recovery guard reuse the ordinary local
runner for durable workflow control and isolated workers for agent execution.
No new daemon Kubernetes identity is introduced. Missing physical custody must
refuse replacement execution until exact retained worker/output evidence can be
reconciled; an observation authored by the pod cannot release that guard.
