# Common human restart for generated children

The command additions compose existing common intervention, interactive policy,
SQLite child epochs, pinned runtime, and sealed workspace custody. This daemon
owns the parent cancellation inventory, runner registry, provider bindings and
configuration reload lock order, so this coordination belongs at its composition
boundary. No separate resume system, credential store, retry queue or workflow
catalog is introduced. Reusable guidance/retry restoration stays in runner;
identity/cancellation and history bounds stay in triggerqueue. Tests exercise the
real HumanService, queue drain, parent capacity and Runner continuation with an
injected contained agent. No complexity or growth baseline is increased.
