# #7031: bound the periodic instance-journal readers

Growth: +67 non-test lines and +0 files in `cmd/goobers`.

- `stalledengineruns.go`: `engineCancelHistory` now keeps a per-journal
  `engineCancelIndex` across sweeps instead of re-parsing the whole instance
  journal on each one. It is the stall sweep's own index of its
  `engine_cancel_requested` annotations, so it stays with the sweep.
- `telemetryretention.go` and `retentiongrace.go`: a retention pass records
  the journal's last sequence when it is created, and the dedupe reads only
  what followed it. `compactInstanceJournal` runs the new tick-skip
  compaction next to the existing window compaction, inside the rollup's
  ingest/reset serialization.

## Could any of it live elsewhere?

The reusable parts are already in `internal/journal`: the incremental
`InstanceLogCursor`, the `InstanceLogLastSeq` watermark, and
`CompactTickSkips`. What is left here is how the stall sweep and the
retention pass use them.
