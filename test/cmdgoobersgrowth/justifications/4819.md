# #4819: lifecycle preflight report

Adds a focused lifecycle report adapter and tests beside the runtime preflight
command. Reusable cleanup evidence and the controlled descendant fixture live
in internal/runtimeplan and internal/platform/proc. The CLI adapter connects the
existing --check-readiness opt-in to those components and reports daemon/worker
limitations without mutating providers or invoking a model.

This readiness train also implements #4816 and #4817 with small CLI adapters
for credential metadata, bounded harness diagnostics and MCP inventory; reusable
probe logic remains in internal/credreadiness and internal/harness. #4878 adds
doctor flags and status rendering for externally scheduled cluster checks, with
recording and freshness logic in internal/k8spreflight, internal/clustercheck
and internal/readservice. Integration preserves main's configured telemetry
connector admission in both normal and diagnostic preflight compilation.
