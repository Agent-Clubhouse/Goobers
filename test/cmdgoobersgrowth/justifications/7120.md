# Backprop gaggle-level defaults and report CLI (#7120)

Growth: one new non-test file, `cmd/goobers/backprop_gaggle.go`, plus small
edits to existing CLI registration files.

## Why the growth belongs in the command package

- **`goobers telemetry gaggle`** is a thin CLI adapter. It parses flags,
  opens the optional read model, calls
  `readservice.StoredGaggleBackprop` and renders text or JSON. It sits beside
  the other `telemetry` subcommands and the help, completion, synopsis and
  capability registration it extends. The report logic, including windows,
  shares, recurring findings, trends and recorded-identifier links, lives in
  `internal/readservice`.
- **`openOptionalReadModel`** is a small helper. The new command and the
  existing `telemetry shadow` command both use it, so it replaces code in the
  shadow command instead of duplicating it.
- **Gaggle default application.** The existing config-load call sites now call
  `instance.ApplyGaggleDefaults`. That function in `internal/instance` holds
  the inheritance rules, so the call sites change by about one line each.

## Could any of it live elsewhere?

Flag parsing and rendering could move to a shared telemetry CLI package once the
broader `cmd/goobers` extraction lands. That is not worth doing for one
command today.
