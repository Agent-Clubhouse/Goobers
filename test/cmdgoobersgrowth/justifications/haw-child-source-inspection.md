# Child source inspection

This command adapter resolves an exact queue-owned child journal and its pinned
workflow for the existing human intervention service. It returns no Runner and
never substitutes catalog definitions. Daemon wiring is the owner of both the
queue and instance layout; reusable inspection semantics live in intervention.
No package-growth baseline is changed. Executable recovery retains its current
policy and epoch fences; this slice does not enable child restart admission.
