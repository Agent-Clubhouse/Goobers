# HAW-HITL restart recovery adapter

The command layer binds the daemon generation registry, current applied workflow
catalog and human authorization service. A retained human restart marker selects
only the dedicated human execution builder; current permission or enablement
refusal defers that continuation without blocking unrelated gaggles. The epoch
keeps its own journal context and allowance, with no second restart admission.

Immutable authority and runtime restoration remain in interactiveaccess, journal
and runner. The new file composes private daemon registries at startup. The
legacy command growth baseline remains unchanged.
