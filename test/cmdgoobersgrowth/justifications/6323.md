# #6323: Evaluate remediation checkpoints against the rebased base

The command package gains checkpoint orchestration that resolves the base SHA
used by the current remediation cycle from the rebase result, with a live base
tip fallback. This keeps diff calculation, structural-collision detection,
no-progress decisions, persisted checkpoint state, and diagnostics on the same
evaluated base instead of stale pull-request metadata.

The logic belongs in the command package because it coordinates existing
provider inputs, live provider reads, git diffing, and checkpoint publication;
it does not introduce a reusable domain component.
