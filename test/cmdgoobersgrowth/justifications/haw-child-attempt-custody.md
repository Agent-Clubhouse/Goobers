# HAW exact child pod authority and custody

The command package binds authenticated pod contracts to its existing private
journal, queue and credential runtime adapters. It verifies the immutable run
identity, executable task/reviewer kind and active physical attempt before
serving credentials or scoped blobs. Signing, bounded ownership memberships,
transactional cleanup and read limits remain in internal packages. The same
output adoption seam caps pod-authored provenance and checks declared byte sizes
before journal custody. This introduces no command or daemon Kubernetes client.
Tests exercise signed HTTP requests through the production credential/blob
adapters, missing or settled custody, and the real generated-run factory.
