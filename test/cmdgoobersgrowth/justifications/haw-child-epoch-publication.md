# Publication from a human child execution

The daemon binds the existing host publisher to the current child epoch and its
interactive credential lease. The only production command additions select the
original accepted repository baseline for excluded-path restoration and require
read-only observation to use the emitting execution's journal. Publication effect
fences and migration belong in triggerqueue, and immutable emitter validation and
provider observations remain in childpublication. The portal exposes that emitter.

The command integration fixture exercises real retained Git forks and the actual
host credential/publication factories, including an automation-resolver trap. It
performs no live provider effects. No baseline or complexity allowance is changed.
