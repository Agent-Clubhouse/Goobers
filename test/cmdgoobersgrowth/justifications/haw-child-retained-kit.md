# HAW-CHD-003 retained generated execution kit

The generated child kit composes command-owned archived config loading, credential
reference derivation and daemon authority. It shares ordinary kit construction
and replaces catalog selection with the exact accepted source and retained
Goober digest. This belongs beside the existing worker kit writer because those
configuration composition functions are command-owned.

Generic source custody and bounded child blob storage stay in internal packages.
The writer receives its blob store and requires current child authority; the
production isolated factory supplies the child-scoped bounded store. It does not
create pods, resolve secrets or widen daemon Kubernetes permissions.
