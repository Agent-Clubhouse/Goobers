# Install typed blocker-resolution session tools

The command package composes the existing live session runtime, source reader,
shared queue and scheduler claims adapter. The optional resolver factory joins
that host assembly beside existing source reader/writer factories. Availability
reflects the installed session/tool plane; it never grants human permission.

Typed tool decoding, source/evidence validation, provider effects, command custody,
HTTP/MCP contracts and journal assessment receipts remain in their reusable internal
packages. Added command lines select and connect those services using the daemon's
existing layout, grants and current applied policy; they do not add a second API
listener or delegate provider credentials to a model process.
