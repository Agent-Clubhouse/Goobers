# Queue pass budget and safe restart waiting explanations

The command package keeps a short host-only execution-context bridge while
bounding each admission sweep. Current typed daemon errors are mapped to a
closed internal queue vocabulary; provider text and credentials are never
persisted as waiting explanations. Shared state transitions and observation
updates remain in triggerqueue and restartintent. Existing intervention receipts
and portal forms surface these reasons without adding a second operation path.
