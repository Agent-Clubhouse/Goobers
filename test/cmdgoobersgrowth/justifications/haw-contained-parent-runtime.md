# HAW-CHD contained parent execution

The daemon owns applied configuration, run journals, credential resolution,
Temporal transport and worker wiring. These command adapters connect that
existing ownership to a distinct signed workflow-parent identity: model-only
credentials, exact execution observations, bounded artifact custody, strict
observation-only journaling, validated result surrender, and child-tool grant
exchange. No caller-supplied actor, policy or lifecycle event grants authority.

Reusable storage, custody projections, signed grants, secret delivery recovery,
bounded HTTP transport and journal branch attribution remain in internal
packages. The command code derives exact retained physical attempt authority
and binds the worker harness to those owners. Signed HTTP and runtime tests
exercise the installed handlers and real queue/journal implementations.

The parent factory, workspace contribution and recovery integration are part
of this private preparation branch. Public opt-in remains gated until the
complete parent/child execution and Portal journey is qualified.
