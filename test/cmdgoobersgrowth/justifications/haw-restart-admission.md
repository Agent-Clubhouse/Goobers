# HAW-HITL restart admission

The daemon adapter composes its existing pinned-generation archive, run-owner
registry, claim ledger, applied definition registry and intervention service.
It stamps trusted human authority and selects independently configured code and
backlog read clients for bounded source admission. It reuses the continuation
eligibility compiler through an extracted applied-snapshot entry point rather
than duplicating it or rereading configuration during the policy lease.

Credential resolution and the lazy policy lease remain in interactiveaccess.
Worktree release verification remains in worktree. Exact ADO branch observation
remains in providers. Restart journal/replay/runtime behavior remains in the
intervention and runner packages. The command files bind those components to
the daemon's existing private registries and lifetime. No baseline repin is
required or performed. Production activation is deferred until the dedicated
interactive execution builder is installed and tested.
