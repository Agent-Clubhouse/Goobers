# #7119: Backprop agent claim log

Growth: +143 non-test lines and +1 file in `cmd/goobers`.

- `telemetryclaim.go` (+125, new): the `goobers telemetry claim` subcommand
  that an agent runs inside its stage. It parses flags (including repeatable
  `--evidence`), refuses credit or blame without evidence, and calls
  `creditgraph.AppendClaim` on `$GOOBERS_TELEMETRY_DIR`. It also holds
  `goobers telemetry claims`, which prints the runner's snapshot of earlier
  stages' claims via `creditgraph.ReadRunClaims`. It is a separate file so
  `telemetry.go` does not grow further.
- `runtime_capabilities.go`, `completionmodel.go`, `clisynopsis.go`,
  `telemetry.go` (+18 net): registry, completion, synopsis, and group help
  entries for the new subcommands.
- `childjournal.go` (+0 net): allows a remote worker to journal its own
  attempt's `backprop-claims` annotation, like the other harness annotations.

## Could any of it live elsewhere?

The claim schema, sanitizing, bounds, file append and read, journal payload,
and verification against recorded provenance live in `internal/creditgraph`;
ingestion lives in `internal/harness`. What remains here is CLI flag handling,
command registration, and the child-journal allowlist, which only exist in
this package.
