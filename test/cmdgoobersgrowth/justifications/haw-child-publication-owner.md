# HAW-CHD delegated child publication owner

The command package already owns current gaggle policy, retained execution
identity, credential materialization, the managed workspace and its live journal.
The publication adapters bind those owners to canonical generated-child push/PR
stages and return verified publication observations through the parent handoff.
Provider credentials remain on the host and cannot enter child pods.

Reusable bounded intent storage, provider observation, immutable reconciliation
and Git publication live in internal/triggerqueue, internal/childpublication and
internal/recovery. Provider-native create-only methods share existing request
construction and preserve ordinary OpenPullRequest update behavior.

The new command files separate typed authority/recording from provider/credential
construction. Behavioral tests drive the production factory, actual multi-stage
runner, parent handoff, and ADO brokered authentication. Public child activation
remains gated by the complete journey and Portal qualification.
