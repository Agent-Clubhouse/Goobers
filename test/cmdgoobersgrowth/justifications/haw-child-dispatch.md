# haw-child-dispatch: command composition review

Child receipts enter the existing daemon trigger drain with a distinct typed launcher, pinned identity and crash reconciliation. The command package is the composition root for scheduler, registry and journal ownership; generic acceptance and lineage transactions remain in internal/triggerqueue and validation remains in internal/childworkflow. It does not add a second trigger service.

Stable HAW design tasks are the planning references until numbered backlog items
are created after review. This declaration applies to this PR against its stacked
base; the shared baseline is deliberately unchanged.
