# HAW contained child factory composition

The daemon composes retained generated source and immutable placement pins with
its existing Temporal client, surrender plane, owned journal and managed child
workspace. The additional command-package code is limited to these existing
private runtime adapters. Worker transport, exact pod termination proof, bounded
blob custody and source validation live in internal packages. There is no new
CLI command, daemon Kubernetes access, local execution fallback or provider
credential delegation. Shared context/result adoption helpers also serve the
contained parent adapter. Integration tests drive the real generated Runner
through these factories and the actual custody executor with an injected worker
transport, verifying the pinned kit, result adoption and observed usage.
