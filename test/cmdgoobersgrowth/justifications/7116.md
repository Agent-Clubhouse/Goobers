# #7116: Backprop ground-truth labels

Growth: +94 non-test lines and +0 files in `cmd/goobers`.

- `telemetry.go` (+77): the `goobers telemetry label` subcommand. It parses
  flags, resolves the default labeler, and calls
  `readservice.RecordGroundTruthLabel`. It sits beside
  `telemetry mark-fix`, the other operator-recorded Backprop metadata command.
- `runtime_capabilities.go`, `completionmodel.go`, `clisynopsis.go`
  (+14 net): registry, completion, and synopsis entries for the new
  subcommand. The telemetry command group moved into
  `telemetryCLICommand()` so the registry `init` body does not grow.
- `telemetrydefectplane.go`, `telemetryquery.go` (+2): carry the new
  cohort `groundTruth` summary across the defect-plane wire conversion.

## Could any of it live elsewhere?

The label store, validation, effective-label resolution, and cohort
re-scoring live in `internal/creditgraph`; run lookup lives in
`internal/readservice`. What remains here is CLI flag handling and command
registration, which only exist in this package.
