# #7393: Claude host-process safety hook

Growth: +36 non-test lines and +1 file in `cmd/goobers`.

- `claudehostsafety.go` (+16): a small stdin/stdout command adapter for the
  private `__claude-host-safety` hook entry point. It rejects arguments and
  delegates hook decoding, command inspection, and the response to
  `internal/hostprocess`.
- `runtime_capabilities.go` (+1): registers that private entry point.
- `daemon.go`, `dispatchagentic.go`, `validate.go`, and `workerwiring.go`
  (+19 net): display preflight warnings in the existing daemon, pod, validation,
  and worker reporting paths. Older or unknown Claude versions retain their
  existing command denies and receive an upgrade warning unless hook
  enforcement was explicitly required.

## Could any of it live elsewhere?

Hook enforcement and command parsing live in `internal/hostprocess`; version
policy, isolated settings, and runtime setup live in `internal/harness`.
The command package retains only command registration, standard-stream wiring,
and presentation of harness diagnostics through its existing operator-facing
reporting paths. The shared growth snapshot is unchanged.
