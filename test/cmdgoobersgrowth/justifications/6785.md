# #6785: Add a cheap bounded status run list

Growth: +60 non-test lines and +0 files in `cmd/goobers`.

- `status.go` adds the command-owned `--runs-only` mode, validates its flag
  combinations, and selects the newest matching runs without invoking the
  expensive fleet and provider-backed status paths.
- `remotereads.go` pushes the mode's filters and bounded lookahead into daemon
  requests so remote status does not exhaustively page through run history.
- `clisynopsis.go` and `completionmodel.go` expose the new status flag through
  the CLI's existing help and completion registries.

The reusable run and API contracts remain in their existing internal packages.
This growth is limited to status command parsing, presentation, and remote CLI
wiring, which are already owned by `cmd/goobers`.
