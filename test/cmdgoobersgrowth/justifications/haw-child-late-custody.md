# HAW child recovery and durable resume composition

The daemon composes the existing queue, journal, managed worktree and worker
transport owners to reconcile the exact retained child pod request before any
new execution or terminal snapshot. Host-only scope markers bind that request
and its original stage; scoped late output remains separate from active model
credential authority. A bounded queue sweep promotes exclusive registry custody
into a cancellable runner behind the parent fence, then resumes the same RunID.
The worker stop/import implementation stays in internal/childpod; repository
writer proof stays in internal/runner and durable fence semantics stay in
internal/triggerqueue. No new CLI command or daemon Kubernetes privilege is added.
