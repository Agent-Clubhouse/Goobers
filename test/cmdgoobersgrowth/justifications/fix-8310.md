# Reusable child-template candidates completion entries (#8310)

`goobers workflow clusters` gained `--templates` and `--cluster-model`, which
print the advisory, review-required reusable child-template candidate report.
The two added lines in cmd/goobers are the shell-completion model entries that
TestCompletionFlagsMatchHandlerFlagSetsAndSynopsis requires for every handler
flag; the synopsis and example edits change no line count. Flag parsing,
evidence loading, candidate evaluation and report rendering live in
internal/workflowcluster; the command layer adds no logic.
