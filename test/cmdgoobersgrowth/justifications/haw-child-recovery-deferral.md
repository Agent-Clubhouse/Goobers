# haw-child-recovery-deferral: command composition review

Startup already owns recovery ordering and runnable capacity. This small adapter classifies refused generated-child recovery, retains custody, releases a runnable reservation and emits an actionable warning without weakening ordinary fatal startup errors. The shared state remains in the queue and scheduler packages.

Stable HAW design tasks are the planning references until numbered backlog items
are created after review. This declaration applies to this PR against its stacked
base; the shared baseline is deliberately unchanged.
