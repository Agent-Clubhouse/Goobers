# HAW-EVT-002: queued human continuation epochs

The command adapter binds the existing interactive policy/source preflight and
pinned human execution builder to the shared trigger ledger. It wires the typed
restart dispatcher and retention inventory into the existing daemon sweep and
pruners. These dependencies are private command composition types, so this
additive adapter belongs beside the existing restart and queue assembly.

Canonical envelopes, bounded immutable attachment custody, source-occurrence
uniqueness, dispatch barriers and reconciliation live in internal/restartintent,
internal/triggerqueue and internal/intervention. No independent queue or direct
launch fallback is added.
