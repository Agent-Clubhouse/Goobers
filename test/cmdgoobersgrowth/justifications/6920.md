# #6920: surrender pre-checkout failures of writable-repo pod stages

Growth: +40 non-test lines and +0 files in `cmd/goobers`.

- `recoverypod.go`: `podRepositoryMaterialized` and its call in
  `publishPodRecovery`. Pod recovery custody skips a writable-repo stage
  whose checkout never created `.git`, so the pod surrenders the stage's
  real failure instead of dying on "not a git repository". Absence is the
  only skip; any other stat error still fails custody closed.
- `dispatchexec.go`: `logStageFailureEnvelope` writes a non-success
  envelope's code and message to the pod's stderr before recovery custody
  runs, so a later infrastructure failure cannot hide the real cause.

## Could any of it live elsewhere?

Both pieces extend the pod supervisor (`dispatch-exec`) and its recovery
custody path, which live in this package and read the dispatcher-stamped
pod environment. Moving them would mean moving that whole path, which is a
separate extraction.
