Issue #6225 centralizes scheduler-state JSON reads and compare-and-swap updates
that were duplicated across backlog cursors and blocked-record maps. The generic
helpers add command-package lines while allowing the migrated call sites to keep
their domain-specific decoding, integrity checks, and exact error wrapping.

The helpers belong in cmd/goobers because they compose the cmd-local
stateclient.Store abstraction and are shared only by the command's scheduler
state implementations; moving them to an internal package would export legacy
command concerns without creating a reusable cross-package contract.
