# #5891: exclude host suspension from maxRunDuration and the stall sweep

Growth: +21 non-test lines and +0 files in `cmd/goobers`.

- `stalledruns.go` (+14 net): the `HostSuspensions` field on
  `stalledSweepDeps` with its nil-safe accessor, and passing the snapshot of
  suspension windows to the execution clock, the journal stall comparison,
  `ExpireRun` and `EscalateStalled`. This is the daemon-only stalled-run
  sweep, which already lives here with the drained-downtime credit it
  parallels.
- `up.go` (+7 net): the daemon reads earlier lifetimes' suspensions from the
  instance log in the same read that feeds the drained-downtime credit,
  observes new suspensions immediately before each sweep (so a suspension
  that just ended is credited by the sweep that would otherwise read it as
  run time), and wires the ledger into the sweep dependencies.

## Could any of it live elsewhere?

The mechanism already does: suspension detection is in
`internal/platform/activetime` (`WallMark`), the ledger, journaling, parsing
and interval arithmetic are in the new `internal/hostsuspend` package, and the
execution-clock and stall-window rules are in `internal/runner`. What remains
here is daemon wiring of the sweep that only exists in this package.
