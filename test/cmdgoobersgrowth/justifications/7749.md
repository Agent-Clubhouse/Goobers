# #7749: Report runtime support and cloud blockers

Growth: +287 non-test lines and +1 production file in `cmd/goobers`.

The validator now projects the feature registry's runner/engine support column
into target-aware `RUNTIME001`-`RUNTIME003` findings. The new command-owned file
keeps that orchestration out of the versioned interpreters: it maps loaded
instance workflows to their canonical feature metadata, reuses the existing
pinned-placement decision path for self-host requirements, and emits local,
engine-configured, or cloud severities through the CLI diagnostics contract.

The remaining command-package growth updates the existing feature discovery,
generated documentation, help, completion, and diagnostics surfaces. Runtime
support types and validation remain in `internal/workflow`; only instance
loading, target selection, source attribution, and CLI rendering stay in the
command package because those dependencies are owned there.
