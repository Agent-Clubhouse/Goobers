# #7869: goobers-cloud bootstrap and cutover check

Growth: +225 non-test lines and +2 production files in `cmd/goobers-cloud`.

`goobers-cloud bootstrap` and `goobers-cloud cutover check` are new operator
commands, so each needs its own command file for flag parsing, database
connection setup and output. The logic lives outside the command package:
eligibility and install checks are in `internal/cloud/cutover`, admission in
`internal/cloud/config`, and role provisioning will come from
`internal/cloud/pgroles`. The command files only parse flags, open the
connections `cmd/goobers-cloud` already owns (URL files, Entra auth, signal
context) and render results, and they reuse the existing `databaseURL` and
`configureDatabaseAuth` helpers rather than duplicating them.
