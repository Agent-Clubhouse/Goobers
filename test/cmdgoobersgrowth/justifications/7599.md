# Child execution observation timeout (#7599)

The four additional non-test lines in `cmd/goobers/childexecutionfence.go`
preserve the production entry point and add an options-forwarding helper for the
existing signed-child HTTP integration fixtures. The command adapter already
owns contract validation and parent-lineage selection, so the helper belongs
beside that adapter and keeps those checks on the test path.

The reusable timeout policy, default, validation, watchdog and independent lease
timers remain in `internal/claimsclient`. Production callers use its default;
the HTTP fixtures can select a generous observation budget while fake-clock
tests in that package verify exact deadlines. No command behavior or shared
growth snapshot is added for the fixtures.
