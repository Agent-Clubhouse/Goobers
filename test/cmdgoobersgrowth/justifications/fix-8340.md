# Per-cluster workflow fitness flag

`goobers workflow clusters --fitness` reports advisory retained-run fitness for
each structural cluster. The command layer only gains the flag's completion
entry and its synopsis and example; both describe a flag that the existing
handler in internal/workflowcluster parses. Run scanning, the configured
workflow digest join, and the per-cluster statistics live in
internal/workflowcluster, so the command package adds no reusable logic.
